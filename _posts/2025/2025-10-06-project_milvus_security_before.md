## 프로젝트 개요
- **프로젝트명** : 사내 HR 시스템 운영 및 UI/UX 고도화
- **기간** : 2022.6 ~ 현재 (진행중)  
- **소속** : (주)밀버스  

사내 HR(인사관리) 시스템은 근태, 조직, 인사 정보를 통합 관리하며 임직원의 인사 행정 업무를 효율화하기 위해 운영되는 사내 핵심 인트라넷 시스템입니다.  
본 프로젝트는 구축 이후 안정적 운영을 기반으로, UI/UX 개선과 프론트엔드·백엔드 기능 고도화를 지속적으로 수행하며 완성도를 높이고 있습니다.  
저는 **사용자 중심의 화면 구조 개선**과 **업무 효율 향상 기능**을 주도적으로 개발하고, 현업 요청을 신속히 반영하여 **인사팀으로부터 긍정적인 평가**를 받았습니다.

## 사용 기술  

| 구분 | 기술 및 도구 | 주요 역할 및 사용 목적 |
|------|---------------|-------------------------|
| **Frontend** | JavaScript, jQuery, JSP, HTML5, CSS3 | 화면 구성, 반응형 UI 구현 |
| **Backend** | Java, Spring Boot | 비즈니스 로직 처리, 데이터 검증 |
| **Database** | MariaDB | 인사 데이터 모델링, 테이블 구조 설계, 쿼리 최적화 |
| **Infra & DevOps** | Apache Tomcat, Linux, Jenkins | 내부 서버 운영 및 배포 관리 |

## 담당 역할
- **UI/UX 개선 주도**  
  - 사용자 중심의 화면 구조 개선 및 디자인 일관성 확보  
  - 인사팀의 실사용 환경을 분석하여 업무 효율을 높이는 기능을 선제적으로 개발  
- **프론트엔드·백엔드 기능 고도화 담당**  
  - 주요 HR 기능(근태, 조직 관리 등)의 신규 기능 개발 및 성능 개선  
  - 공통 모듈 리팩토링을 통한 유지보수성 향상  
- **시스템 운영 및 이슈 대응 담당**  
  - 사용자 문의 대응, 장애 원인 분석 및 긴급 조치 수행


## 주요 업무

### 1. UI/UX 개선 및 화면 구조 개편
- `JavaScript`, `jQuery`, `CSS`를 활용하여 반응형 웹 UI를 구성  
- JSP 기반 레이아웃 구조를 개선하여 화면 재사용성과 유지보수성 향상  
- 사용자 피드백을 수집하여 업무 흐름에 맞는 UX 설계를 반영    

### 2. 프론트엔드·백엔드 기능 고도화
- **Spring Boot + JSP 환경**에서 프론트엔드와 백엔드 간 데이터 연동 구조를 개선  
- 근태 관리, 조직 관리 등 핵심 모듈의 기능 개선 및 신규 기능 개발을 수행  

### 3. 신규 기능 구축 및 유지보수
- 사용자 요청을 기반으로 신규 기능을 설계·개발·테스트 진행  
- 현업 요청사항의 우선순위를 관리하고 정기 릴리즈를 운영  
- 장애 발생 시 로그 분석을 통해 원인 진단 및 실시간 대응을 수행  

### 4. 협업 및 커뮤니케이션
- 인사팀, 총무팀 등 주요 부서와 협업하여 요구사항을 정의·검증·적용  
- 기술적 제약을 고려한 솔루션 설계를 통해 부서 간 커뮤니케이션 효율 증대  


## 프로젝트 결과
- UI/UX 개선으로 사용자 경험과 업무 효율이 향상  
- 프론트엔드·백엔드 기능 고도화로 시스템 성능과 안정성을 강화  
- 현업 요청 신속 반영 체계가 자리 잡아 인사팀 만족도 만족도 및 협업 효율 향상  


## 성과 및 성장
- 사용자 중심 설계 역량과 데이터 기반 개선 의사결정 역량을 강화  
- 프론트엔드-백엔드 통합 개선 경험을 통해 시스템 구조 이해도 향상  
- 쿼리 튜닝 및 데이터 모델링 개선으로 성능 최적화 경험을 축적  
- 인사팀과의 긴밀한 협업을 통해 신뢰 기반의 커뮤니케이션을 확립

본 프로젝트는 장기 운영을 통한 지속적 개선을 지향하며, 사용자 중심 개편과 기능 고도화로 내부 고객의 만족도를 높인 사례입니다.
