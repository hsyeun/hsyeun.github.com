## 프로젝트 개요
- **프로젝트명** : 사내 HR 시스템 운영 및 UI/UX 고도화
- **기간** : 2022.6 ~ 현재 (진행중)  
- **소속** : (주)밀버스  

사내 HR(인사관리) 시스템은 근태, 조직, 인사 정보를 통합 관리하며 임직원의 인사 행정 업무를 효율화하기 위해 운영되는 사내 핵심 인트라넷 시스템입니다.  
본 프로젝트는 시스템 구축 이후 장기 운영 및 기능 개선을 통해 안정성과 사용성을 높이는 것을 목표로 하고 있습니다.  
저는 **UI/UX 개선과 기능 고도화를 주도하며, 사용자 중심 개선 활동을 지속적으로 수행**하고 있습니다.  

## 사용 기술  

| 구분 | 기술 및 도구 | 주요 역할 및 사용 목적 |
|------|---------------|-------------------------|
| **Frontend** | JavaScript, jQuery, JSP, HTML5, CSS3 | 화면 구성, 반응형 UI 구현 |
| **Backend** | Java, Spring Boot | 비즈니스 로직 처리, 데이터 검증 |
| **Database** | MariaDB | 인사 데이터 모델링, 테이블 구조 설계, 쿼리 최적화 |
| **Infra & DevOps** | Apache Tomcat, Linux, Jenkins | 서버 운영 및 배포 관리 |

## 담당 역할
- **UI/UX 개선 주도**  
  - 사용자 중심의 화면 구조 개선 및 디자인 일관성 확보  
  - 인사팀의 실사용 환경을 분석하여 업무 효율을 높이는 기능을 선제적으로 개발  
- **프론트엔드·백엔드 기능 고도화 담당**  
  - 주요 HR 기능(근태, 조직 관리 등)의 신규 기능 개발 및 성능 개선  
  - 공통 모듈 리팩토링을 통한 유지보수성 향상  
- **시스템 운영 및 이슈 대응 담당**  
  - 사용자 문의 대응, 장애 원인 분석 및 긴급 조치 수행


## 주요 업무

### 1. UI/UX 개선 및 화면 구조 개편
- `JavaScript`, `jQuery`, `CSS`를 활용하여 반응형 웹 UI를 구성하였습니다.  
- JSP 기반 레이아웃 구조를 개선하여 화면 재사용성과 일관성을 높였습니다.  
- 사용자 피드백을 수집하여 업무 흐름에 맞는 UX 설계를 반영하였습니다.  
- 공통 UI 컴포넌트(입력폼, 버튼, 테이블 등)를 재정의하여 개발 효율을 향상시켰습니다.  

### 2. 프론트엔드·백엔드 기능 고도화
- **Spring Boot + JSP 환경**에서 프론트엔드와 백엔드 간 데이터 연동 구조를 개선하였습니다.  
- 근태 관리, 조직 관리 등 **핵심 모듈의 기능 개선 및 신규 기능 개발**을 수행하였습니다.  
- **MariaDB 테이블 구조를 개선**하고 데이터 무결성을 강화하였습니다.  
- 쿼리 성능 최적화를 통해 **조회 속도 및 시스템 안정성**을 높였습니다.  

### 3. 신규 기능 구축 및 유지보수
- 사용자 요청을 기반으로 **신규 기능을 설계·개발·테스트**하였습니다.  
- **현업 요청사항의 우선순위를 관리**하고 정기 릴리즈를 운영하였습니다.  
- 장애 발생 시 로그 분석을 통해 **원인 진단 및 실시간 대응**을 수행하였습니다.  

### 4. 협업 및 커뮤니케이션
- 인사팀, 총무팀 등 주요 부서와 협업하여 **요구사항을 정의·검증·적용**하였습니다.  
- UI 시안 및 개선안을 제안하여 **현업 관점의 사용성 개선**을 이끌었습니다.  
- **기술적 제약을 고려한 솔루션 설계**를 통해 부서 간 커뮤니케이션 효율을 높였습니다.  


## 성과 및 성장
- 프론트엔드·백엔드 통합 개발 PL로서 기술 리드 및 협업 관리 경험 확보  
- React 중심의 상태 관리·컴포넌트 구축 역량 강화  
- Tableau Embedded API 기반 리포트 임베딩 및 사용자 제어 로직 설계 경험 축적  
- AWS 환경 수동 배포 및 서버 운영 관리 경험  
- 사용자 중심 UI 개선 및 장기적 서비스 안정화 경험 강화  
- 요구사항을 기술적 솔루션으로 전환하는 리더십 역량 강화  

본 프로젝트는 **React 컴포넌트 설계, 실시간 상태 관리, BI 임베딩(Tableau, Superset, Redash), 사용자 중심 UI 설계**를 결합한 사례로, 프론트엔드 중심의 기술 리더십과 데이터 기반 서비스 구축 능력을 입증한 대표 프로젝트입니다.
